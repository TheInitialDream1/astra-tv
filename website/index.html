A FEW THINGS TO KNOW

关于这个宇宙。

Android 版还是网页套壳吗？

当前 Android 版使用 Java 原生控件、OpenGL ES 3 和 MediaPipe 原生推理，不包含 WebView，也不依赖电脑服务器。仓库保留 Three.js 浏览器原型，官网的实时星系演示同样运行在浏览器中，两者与 Android 安装包分别构建。

现在是原生 4K、稳定 60 FPS 吗？

还不是。现有测试电视向应用提供 1920 × 1080 窗口；星云采用独立的较低分辨率缓冲，界面和图标在窗口分辨率绘制。强制 4K 的尝试未达到流畅要求。摄像头与图形也会争用性能，因此不承诺所有机型的帧率。

能清除电视上的所有广告吗？

不能保证。维护工具提供组件停用和私有 DNS 方案，需针对具体固件核对；与视频内容同域的广告等可能无法过滤。当前原生执行与恢复仍需实机联调，不会把其他小米型号的清单当成这台电视的验证结果。

摄像头画面会上传吗？

手势图像在电视本机进入 MediaPipe 模型，不上传、不录制。天气使用配置的城市坐标访问 Open-Meteo；本机维护连接的是电视自己的 ADB。第三方独立插件有各自的网络、权限和配置，应分别查看其说明。

现在能当作成熟的量产桌面使用吗？

目前是 v0.4.0 实验性预览项目。遥控导航、原生界面、星云渲染与维护基础能力已经实现；手势准确性、不同电视的摄像头接口、系统维护执行和部分厂商功能仍在完善。推荐保留原桌面并从小范围体验开始。
